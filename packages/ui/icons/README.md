## About

A collection of icons, implemented as react components, to be used in react-based applications.

Use `icons/react` (components) and `icons/svg` (source files). They have a `viewBox`, scale with CSS and follow `currentColor`.
The per-size folders (`icons/cancel/large`, …) are legacy: see [icons.steering.md](./icons.steering.md) for the standard and how to migrate, and [legacy-map.json](./legacy-map.json) for the old-to-new mapping.

```jsx
import { Close, ItemTypeDataset } from "@digital-science/figshare-fcl/icons/react";
```
