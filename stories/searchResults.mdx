# SearchResults

A dropdown search results component with infinite scroll support, loading states, error handling, and item selection.

## Basic Usage

<Cover kind={"card"}>
  {() => (
    <ValueProvider initialValue={{ items: [{ id: 1, value: "Option 1" }, { id: 2, value: "Option 2" }, { id: 3, value: "Option 3" }], search: "", selectedItem: null }}>
      {(state, setState) => (
        <div style={{ width: "450px", marginTop: "36px" }}>
          <SearchResults
            hasResults={state.items.length > 0}
            placeholder="Search items..."
            search={state.search}
            onChangeSearchValue={(search) => setState({ ...state, search })}
            onLoadMore={() => console.log("Load more")}
            onSelect={(selectedItem) => setState({ ...state, selectedItem })}
          >
            {state.items.map((item) => (
              <SearchResultItem key={item.id} value={item}>
                {item.value}
              </SearchResultItem>
            ))}
          </SearchResults>
          {state.selectedItem && (
            <div style={{ marginTop: "16px" }}>
              Selected: {state.selectedItem.value}
            </div>
          )}
        </div>
      )}
    </ValueProvider>
  )}
</Cover>

## Multi-State Demo

<Cover kind={"card"}>
  {() => {
    const initialItems = Array.from({ length: 8 }, (_, i) => ({
      id: i,
      value: `Item ${i + 1}`,
    }));
    return (
      <ValueProvider initialValue={{ items: initialItems, search: "", selectedItem: null, demoState: "normal", loading: false, error: null }}>
        {(state, setState) => {
          const handleLoadMore = () => {
            setState({ ...state, loading: true });
            setTimeout(() => {
              const newItems = Array.from(
                { length: 4 },
                (_, i) => ({
                  id: state.items.length + i,
                  value: `Item ${state.items.length + i + 1}`,
                })
              );
              setState({ ...state, items: [...state.items, ...newItems], loading: false });
            }, 800);
          };
          const triggerError = () => {
            setState({ ...state, demoState: "error", error: "Connection failed. Unable to load results." });
          };
          const resetError = () => {
            setState({ ...state, demoState: "normal", error: null });
          };
          return (
            <div style={{ width: "450px" }}>
              <div style={{ marginBottom: "16px", display: "flex", gap: "8px" }}>
                <button onClick={() => setState({ ...state, demoState: "normal" })}>Normal</button>
                <button onClick={() => setState({ ...state, demoState: "loading" })}>Loading</button>
                <button onClick={triggerError}>Error</button>
              </div>

              <SearchResults
                hasResults={state.items.length > 0 && !state.error}
                loading={state.demoState === "loading" || state.loading}
                error={state.demoState === "error" ? state.error : null}
                placeholder="Search items..."
                search={state.search}
                onChangeSearchValue={(search) => setState({ ...state, search })}
                onLoadMore={handleLoadMore}
                onSelect={(selectedItem) => setState({ ...state, selectedItem })}
                noResultsMessage="No items found"
                retry={
                  state.error
                    ? {
                        message: "Try Again",
                        action: resetError,
                      }
                    : undefined
                }
              >
                {state.items.map((item) => (
                  <SearchResultItem key={item.id} value={item}>
                    {item.value}
                  </SearchResultItem>
                ))}
              </SearchResults>

              {state.selectedItem && (
                <div style={{ marginTop: "16px" }}>
                  <strong>Selected:</strong> {state.selectedItem.value}
                </div>
              )}
            </div>
          );
        }}
      </ValueProvider>
    );
  }}
</Cover>

## Component Features

- **Search Input**: Built-in search field that triggers visibility when 3+ characters are entered
- **Infinite Scroll**: Automatically loads more items when scrolling within 10px of bottom
- **Loading State**: Shows animated loader while fetching data
- **Error Handling**: Displays error messages with optional retry button
- **Empty State**: Customizable message when no results are found
- **Item Selection**: Click items to select them; dropdown closes automatically
- **Context Integration**: Uses React Context for selection callbacks
- **Keyboard Navigation**: Full keyboard accessibility support
- **Click Outside**: Closes dropdown when clicking outside

## Accessibility

- Input has proper `aria-expanded` attribute
- Items are rendered as buttons for keyboard navigation
- Focus management included
- Keyboard shortcuts: Escape to close, Enter to select
