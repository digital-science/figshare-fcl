# PasswordStrength

A component that displays password strength requirements and validation status. It shows visual feedback with icons (dot, checkmark, or warning) for each rule and provides screen reader announcements of failed requirements.

## Basic Usage

<Cover kind={"card"}>
  {() => (
    <div style={{ width: "372px", padding: "12px" }}>
      <PasswordStrength
        rules={[
          {
            text: "a lowercase character",
            passed: true,
          },
          {
            text: "a special character",
            passed: true,
          },
          {
            text: "an uppercase character",
            passed: false,
          },
          {
            text: "at least 10 characters",
            passed: false,
          },
          {
            text: "a number",
            passed: false,
          },
        ]}
        text="Please make sure the password contains:"
      />
    </div>
  )}
</Cover>

## Props

- **allRulesPassedText** (string, default: ""): Text displayed when all rules are passed
- **failedRuleType** (oneOf: "default" | "error", default: "default"): Visual styling for failed rules. Use "error" for red background highlighting
- **passed** (boolean, default: false): Whether all password rules have been passed
- **rules** (array, default: []): Array of rule objects with `text` (string) and `passed` (boolean) properties
- **text** (string, default: ""): Header text displayed before the rules list

## Accessibility

- Uses `aria-live="assertive"` for screen reader announcements of failed password requirements
- Icons include proper `aria-label` attributes for accessibility
- Failed rules are visually distinguished when `failedRuleType="error"` is set
- Screen reader users receive a message listing all failed requirements
