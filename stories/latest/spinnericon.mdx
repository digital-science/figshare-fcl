## Overview

An animated loading spinner icon component. Displays a rotating loader with configurable sizes and blend modes for use in loading states.

<Cover kind={"story"}>
  {() => (
    <div style={{ display: "flex", gap: "24px", padding: "24px" }}>
      <SpinnerIcon size="small" />
      <SpinnerIcon size="medium" />
      <SpinnerIcon size="large" />
    </div>
  )}
</Cover>

```jsx
import { SpinnerIcon } from "@digital-science/figshare-fcl/latest/SpinnerIcon";

export default function SpinnerOverview() {
  return (
    <div style={{ display: "flex", gap: "24px" }}>
      <SpinnerIcon size="small" />
      <SpinnerIcon size="medium" />
      <SpinnerIcon size="large" />
    </div>
  );
}
```

The component can be imported from `@digital-science/figshare-fcl/latest`.
