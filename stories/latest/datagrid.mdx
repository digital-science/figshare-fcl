## Overview

A flexible data grid layout component with support for headers, subheaders, content areas, and rows. Perfect for displaying structured data in a tabular format.

<Canvas of={DataGridStories.Overview} />

```jsx
import { DataGrid, DataGridHeader, DataGridSubheader, DataGridContent, DataGridRow } from "@digital-science/figshare-fcl/latest/DataGrid";

export default function DataGridOverview() {
  return (
    <DataGrid>
      <DataGridHeader>
        <DataGridRow style={{ fontWeight: "bold", padding: "12px" }}>
          <div style={{ flex: 1 }}>Name</div>
          <div style={{ flex: 1 }}>Status</div>
          <div style={{ flex: 1 }}>Date</div>
        </DataGridRow>
      </DataGridHeader>
      <DataGridContent>
        <DataGridRow style={{ padding: "12px" }}>
          <div style={{ flex: 1 }}>Item 1</div>
          <div style={{ flex: 1 }}>Active</div>
          <div style={{ flex: 1 }}>2024-01-15</div>
        </DataGridRow>
        <DataGridRow style={{ padding: "12px" }}>
          <div style={{ flex: 1 }}>Item 2</div>
          <div style={{ flex: 1 }}>Pending</div>
          <div style={{ flex: 1 }}>2024-01-14</div>
        </DataGridRow>
      </DataGridContent>
    </DataGrid>
  );
}
```

The component can be imported from `@digital-science/figshare-fcl/latest`.

## Sub-Components

The DataGrid component exports several sub-components:

- **DataGridHeader** - Header section container
- **DataGridSubheader** - Optional subheader section
- **DataGridContent** - Main content area
- **DataGridRow** - Individual row container

### Basic DataGrid

```jsx

      <div style={{ flex: 1 }}>Status</div>
    </DataGridRow>
  </DataGridHeader>
  <DataGridContent>
    <DataGridRow style={{ padding: "12px" }}>
      <div style={{ flex: 1 }}>1</div>
      <div style={{ flex: 2 }}>Research Paper</div>
      <div style={{ flex: 1 }}>Published</div>
    </DataGridRow>

      <div style={{ flex: 1 }}>2</div>

      <div style={{ flex: 1 }}>In Review</div>

```
