## Overview

A flexible data grid layout component built with flex instead of semantic `<table>` elements. Uses a compound component pattern with `DataGrid.Header`, `DataGrid.Subheader`, `DataGrid.Content`, `DataGrid.Row`, and `DataGrid.Cell`. All styling is driven by `data-*` attributes — no class toggling needed.

<Canvas of={DataGridStories.Overview} />

```jsx
import { DataGrid } from "@digital-science/figshare-fcl/latest/DataGrid";

<DataGrid>
  <DataGrid.Header>
    <DataGrid.Subheader>Name</DataGrid.Subheader>
    <DataGrid.Subheader>Status</DataGrid.Subheader>
    <DataGrid.Subheader>Date</DataGrid.Subheader>
  </DataGrid.Header>
  <DataGrid.Content>
    <DataGrid.Row>
      <DataGrid.Cell>Item 1</DataGrid.Cell>
      <DataGrid.Cell>Active</DataGrid.Cell>
      <DataGrid.Cell>2024-01-15</DataGrid.Cell>
    </DataGrid.Row>
  </DataGrid.Content>
</DataGrid>
```

The component can be imported from `@digital-science/figshare-fcl/latest`.

## Sub-Components

- **DataGrid.Header** — Header row container with tertiary background
- **DataGrid.Subheader** — Header cell (also usable as a standalone info row, e.g. "Showing 1-50 of 150")
- **DataGrid.Content** — Body container that holds rows
- **DataGrid.Row** — Individual row with top border separator
- **DataGrid.Cell** — Individual cell — flex column by default

### Cell Sizing

All `data-size` values side by side: `s`, `s2`, `m`, `grow`, `shrink`, `normal`.

### Cell Layout

Use `data-cell-layout` to control content alignment and direction within cells. Values can be combined with space separation (e.g. `"center row"`).

<Canvas of={DataGridStories.CellLayout} />

### Text Alignment

Use `data-align` for simple text alignment (`left`, `center`, `right`).

<Canvas of={DataGridStories.TextAlignment} />

### Density Modes

Set `data-cell-padding` on the `DataGrid` container to control cell density. This adjusts CSS variables `--cell-width-padding` and `--cell-height-padding` that all cells inherit.

<Canvas of={DataGridStories.DensityModes} />

### Hover and Striped

Set `data-hover="true"` for row hover highlights, or `data-striped="true"` for alternating row backgrounds. Both can be combined.

<Canvas of={DataGridStories.HoverAndStriped} />

### Text Wrapping and Truncation

Use `data-wrap="word"` for word wrapping or `data-truncate="true"` for single-line ellipsis.

<Canvas of={DataGridStories.TextWrappingAndTruncation} />

### Root Rows

Use `data-root-row="true"` on rows to highlight them as group headers in hierarchical/tree tables.
