## Overview

A versatile alert component for displaying messages with different types (info, warning, error, success, notice), variants (solid, translucent), and dismissible options.

<Cover kind={"story"}>
  {() => (
    <div style={{ display: "flex", flexDirection: "column", gap: "12px" }}>
      <Alert type="info" title="Information" message="This is an informational alert" persistent />
      <Alert type="success" title="Success" message="The operation completed successfully" persistent />
      <Alert type="warning" title="Warning" message="Please review this warning message" persistent />
      <Alert type="error" title="Error" message="An error occurred" persistent />
    </div>
  )}
</Cover>

```jsx
import { Alert } from "@digital-science/figshare-fcl/latest/Alert";

export default function AlertOverview() {
  return (
    <div style={{ display: "flex", flexDirection: "column", gap: "12px" }}>
      <Alert type="info" title="Information" message="This is an informational alert" persistent />
      <Alert type="success" title="Success" message="The operation completed successfully" persistent />
      <Alert type="warning" title="Warning" message="Please review this warning message" persistent />
      <Alert type="error" title="Error" message="An error occurred" persistent />
    </div>
  );
}
```

The component can be imported from `@digital-science/figshare-fcl/latest`.

## Sub-Components

The Alert component exports several sub-components:

- **Alert.Icon** - Icon display based on alert type
- **Alert.Title** - Alert title element
- **Alert.Description** - Alert message/description element
- **Alert.Close** - Dismiss button for non-persistent alerts
