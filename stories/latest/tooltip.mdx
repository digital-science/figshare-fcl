## Overview

A flexible tooltip component for displaying contextual information. Uses floating UI for positioning and supports interactive tooltips with custom content.

<Cover kind={"story"}>
  {() => (
    <div style={{ display: "flex", gap: "24px", padding: "40px", justifyContent: "center" }}>
      <Tooltip>
        <Tooltip.Trigger asChild>
          <Button kind="tertiary" span="icon" title="Hover for tooltip">
            <Button.Icon>ℹ️</Button.Icon>
          </Button>
        </Tooltip.Trigger>
        <Tooltip.Content>Helpful tooltip text</Tooltip.Content>
      </Tooltip>
    </div>
  )}
</Cover>

```jsx
import { Tooltip } from "@digital-science/figshare-fcl/latest/Tooltip";
import { Button } from "@digital-science/figshare-fcl/latest/Button";

export default function TooltipOverview() {
  return (
    <Tooltip>
      <Tooltip.Trigger asChild>
        <Button kind="tertiary">Hover me</Button>
      </Tooltip.Trigger>
      <Tooltip.Content>Helpful tooltip text</Tooltip.Content>
    </Tooltip>
  );
}
```

The component can be imported from `@digital-science/figshare-fcl/latest`.

## Sub-Components

The Tooltip component exports several sub-components:

- **Tooltip.Trigger** - The element that triggers the tooltip (accepts asChild prop)
- **Tooltip.Content** - The tooltip content wrapper
- **Tooltip.Close** - Optional close button for dismissible tooltips
- **Tooltip.Context** - React Context for tooltip state
