## Overview

A container component that manages and displays a list of alert messages. Messages can be added or removed by dispatching `alerts:message` custom events. This component works in conjunction with the Alert component to create alert systems with proper message management.

<Canvas of={AlertsStories.Overview} />

The component can be imported from `@digital-science/figshare-fcl/latest`.

Use the `pushAlert`, `clearAlerts`, and `popAlert` utilities to manage alerts:

```jsx
import { Alerts, pushAlert, clearAlerts, popAlert } from "@digital-science/figshare-fcl/latest/Alerts";

// Push a new alert
pushAlert({
  channel: "my-alerts-channel",
  type: "success", // "info" | "warning" | "error" | "success" | "notice"
  title: "Optional Title",
  content: "Alert message content",
  persistent: false, // if false, shows close button
  timeout: 5000, // optional: auto-dismiss after milliseconds
});

// Clear all alerts in a channel
clearAlerts("my-alerts-channel");

// Remove a specific alert by ID
popAlert("my-alerts-channel", "alert-id");
```
