## Overview

A flexible layout block component (also exported as Box) for creating structural layouts. Supports custom tags, kinds, and semantic markup with support for right-to-left text direction.

<Canvas of={BlockStories.Overview} />

```jsx
import { Block } from "@digital-science/figshare-fcl/latest/Block";

export default function BlockOverview() {
  return (
    <div style={{ display: "flex", flexDirection: "column", gap: "12px" }}>
      <Block>Default Block</Block>
      <Block kind="layout-columns" style={{ display: "flex", gap: "12px" }}>
        <div>Column 1</div>
        <div>Column 2</div>
      </Block>
    </div>
  );
}
```

The component can be imported from `@digital-science/figshare-fcl/latest`.

## Examples

### Layout Kinds

<Canvas of={BlockStories.LayoutKinds} />

```jsx
import { Block } from "@digital-science/figshare-fcl/latest/Block";

// Row layout
<Block kind="layout-rows">
  <div>Row 1</div>
  <div>Row 2</div>
</Block>

// Column layout
<Block kind="layout-columns" style={{ display: "flex", gap: "12px" }}>
  <div>Column 1</div>
  <div>Column 2</div>
  <div>Column 3</div>
</Block>
```

### Custom HTML Tags

<Canvas of={BlockStories.CustomHTMLTags} />

```jsx
import { Block } from "@digital-science/figshare-fcl/latest/Block";

<Block tag="section">This is a section block</Block>
<Block tag="article">This is an article block</Block>
<Block tag="main">This is a main block</Block>
```
