## Overview

A flexible text component for rendering typography with support for multiple kinds, weights, colors, wrapping, and text alignment.

<Cover kind={"story"}>
  {() => (
    <div style={{ display: "flex", flexDirection: "column", gap: "16px" }}>
      <Text kind="title-1">Title 1</Text>
      <Text kind="body">Body text</Text>
      <Text kind="caption">Caption text</Text>
    </div>
  )}
</Cover>

```jsx
import { Text } from "@digital-science/figshare-fcl/latest/Text";

export default function TextOverview() {
  return (
    <div style={{ display: "flex", flexDirection: "column", gap: "16px" }}>
      <Text kind="title-1">Title 1</Text>
      <Text kind="body">Body text</Text>
      <Text kind="caption">Caption text</Text>
    </div>
  );
}
```

The component can be imported from `@digital-science/figshare-fcl/latest`.
