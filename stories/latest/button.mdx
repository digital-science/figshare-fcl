## Overview

A versatile button component with multiple kinds (primary, secondary, tertiary, inverted, input), emphasis levels (high, low, success, danger), and layout options.

## Sub-Components

The Button component exports several sub-components:

- **Button.Label** - Text content wrapper with wrapping and ellipsis options
- **Button.Icon** - Icon slot with sizing and blending options
- **Button.InteractiveIcon** - Interactive icon with click and keyboard handlers
- **Button.IconGroup** - Groups multiple icons with proper spacing
- **Button.Loading** - Shows loading state with spinner and optional text
