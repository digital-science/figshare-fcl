# Presentation
---

Large illustrations for empty states, confirmations and onboarding, from projects to individual publications or simple quotations. Source files are in `icons/svg/presentation/`, components in `icons/react/presentation/`.

<Canvas of={PresentationStories.Presentation} />
```jsx
import { PresentationQuote, PresentationEnvelopeSuccess } from "@digital-science/figshare-fcl/icons/react";

<PresentationQuote color="var(--color-icon-secondary)" style={{ height: 80, width: "auto" }} />
```

By default the icons keep their original colours (`#8D8D8D`, or two-tone for `EmbedCode`, `EmbedTitle`, `EnvelopeError` and `EnvelopeSuccess`). Pass `blend` to render in `currentColor`, or override with `color` and `secondaryColor`.

Available: CheckMark, Collection, EmbedCode, EmbedTitle, EnvelopeError, EnvelopeSuccess, Exclamation, Ftp, Note, Project, Publications, Quote, Ribbon.
