# Figshare and Media
---

The figshare logo, plus third-party and social brand icons. All of them have a `viewBox` and take their size from CSS (`width`/`height`/`font-size`);
everything except the brand-colour `FigshareLogo` follows `currentColor`.

## Logo

Source files are in `icons/svg/figshare/`, components in `icons/react/figshare/`.

- `FigshareLogo`: brand colours. Supports `animate` (loading pulse) and `grayscale`.
- `FigshareLogoMono`: single colour, follows `currentColor`.
- `FigshareWordmark`: the "figshare" text, `currentColor`.
- `FigshareLogoFull`: logo and wordmark side by side, `currentColor`.

<Canvas of={FigshareStories.Banner} />

```jsx
import { FigshareLogo, FigshareLogoMono, FigshareWordmark } from "@digital-science/figshare-fcl/icons/react";

<FigshareLogo animate style={{ height: 60, width: "auto" }} />
<FigshareLogoMono style={{ height: 60, width: "auto", color: "#55636d" }} />
<FigshareWordmark style={{ height: 60, width: "auto" }} />
```

## Integrations

Bitbucket, FTP, GitHub and GitLab are now single-colour. Colour them with `color`.

<Canvas of={FigshareStories.Integrations} />

```jsx
import { Bitbucket, FtpIntegration, Github, Gitlab, Orcid, OrcidSolid, Rss } from "@digital-science/figshare-fcl/icons/react";

<Github style={{ width: 48, height: 48 }} />
<Orcid style={{ height: 36, width: "auto" }} />   {/* ORCID wordmark */}
<OrcidSolid style={{ width: 48, height: 48 }} />   {/* ORCID iD badge */}
```

## Social media

`Twitter` replaces both `twitter` and `twitter_inverted`. Pick the colour with `color`.

<Canvas of={FigshareStories.SocialMedia} />

```jsx
import { Facebook, Bluesky, Linkedin, Twitter, Vimeo } from "@digital-science/figshare-fcl/icons/react";

<Facebook color="#4267B2" style={{ width: 30, height: 30 }} />
```

### Inverted

There is no separate inverted component. The icons are a filled badge with the glyph cut out, so swapping the colours means a white badge (`color="#fff"`) on a background in the brand colour. Use this on dark or coloured surfaces such as the footer.

<Canvas of={FigshareStories.SocialMediaInverted} />

```jsx
<div style={{ background: "#4267B2", padding: 12, borderRadius: 8, display: "flex" }}>
  <Facebook color="#fff" style={{ width: 30, height: 30 }} />
</div>
```
