# Item type
---

Icons that represent article item types. Source files are in `icons/svg/item-type/`, components in `icons/react/item-type/`.
Each is a 40×24 badge with the glyph cut out of it, so the badge takes `currentColor` and the glyph shows whatever is behind it.

<Canvas of={ItemTypeStories.Gallery} />

```jsx
import { ItemTypeDataset, ItemTypePreprint } from "@digital-science/figshare-fcl/icons/react";

// or straight from the folder
import { Dataset, Preprint } from "@digital-science/figshare-fcl/icons/react/item-type";

<ItemTypeDataset color="var(--color-icon-secondary)" style={{ height: 24, width: "auto" }} />
```

Available: Book, Collection, Dataset, Figure, Media, Metadata, OnlineResource, Paper, Performance, Poster, Preprint, Presentation, Project, Software, Thesis, Workflow.
