# Migrating from the legacy icons
---

The old per-size icons (`icons/<name>/<small|medium|large>`) are deprecated. Use `icons/react` (components) or `icons/svg` (files) instead:
one icon per concept, sized with CSS, coloured with `currentColor`. See `packages/ui/icons/icons.steering.md` for the full guide.

```jsx
// before
import CancelLarge from "@digital-science/figshare-fcl/icons/cancel/large";
<CancelLarge className={styles.icon} />

// after
import { Close } from "@digital-science/figshare-fcl/icons/react";
<Close style={{ width: 18 }} />
```
