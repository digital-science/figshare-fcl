# Icons
---

Every icon lives in `packages/ui/icons/svg` (source) and `packages/ui/icons/react` (components generated from them).
Each one has a `viewBox`, no fixed size, and uses `currentColor`, so it scales with `font-size` and takes the surrounding text colour.

- Click an icon to copy its import.
- Custom sets have their own pages: [Figshare](?path=/docs/icons-figshare--docs), [Item type](?path=/docs/icons-itemtype--docs), [Presentation](?path=/docs/icons-presentation--docs).
- Coming from the old `icons/<name>/<size>` imports? See [Migration](?path=/docs/icons-migration--docs).

```jsx
import { Close, Search, ItemTypeDataset } from "@digital-science/figshare-fcl/icons/react";

<Close />                              {/* 1em wide, currentColor */}
<Search color="var(--color-brand)" />  {/* colour via prop... */}
<Search style={{ width: 24 }} />       {/* ...or size via style */}
<ItemTypeDataset />
```
