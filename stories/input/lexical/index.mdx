## Overview

A textarea which allows users to input more complex HTML markup text. 
Users can mark portions or the whole content as paragraphs, headings or emphasise or underline text in various ways.


<Canvas of={TextEditorStories.Overview} />


The component can be imported from:

```jsx
import Editor from "@digital-science/figshare-fcl/textEditor/Lexical";

function MyTextEditor() {
  const [text, setText] = useState("<b>Initial text or markup</b>");

  return <Editor value={text} onChange={(e) => setText(e.target.value)} />;
}
```

The editor only reads `value` when it mounts. To replace the content from outside (for example a "Reset" button),
remount it by changing its `key`.
