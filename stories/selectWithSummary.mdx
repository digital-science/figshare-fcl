# SelectWithSummary

A dual-state select component that combines a searchable dropdown with a summary display of selected items. It tracks both touched values and preselected options separately, supporting both controlled and uncontrolled patterns.

## Features

- **Dual State Tracking**: Maintains separate state for touched selections and preselected values
- **Searchable Options**: Built-in search functionality for large option lists
- **Summary Display**: Shows selected items as interactive list below the select
- **Loading States**: Separate loading states for select dropdown and summary
- **Error Handling**: Full error state support with retry actions for both select and summary
- **Flexible Sizing**: Support for small, medium, and large variants
- **Accessibility**: Full ARIA support and keyboard navigation
- **Controlled & Uncontrolled**: Works with both controlled and uncontrolled patterns

## Basic Usage

Renders a select with summary display of chosen items.

<Cover kind={"card"}>
  {() => {
    const options = [
      { name: "JavaScript", value: "js" },
      { name: "TypeScript", value: "ts" },

## Loading State

Shows loading indicator when fetching options.

<Cover kind={"card"}>
  {() => {
    const options = [
      { name: "JavaScript", value: "js" },
      { name: "TypeScript", value: "ts" },
      { name: "Python", value: "py" },
    ];

    return (
      <ValueProvider initialValue={{ value: undefined, isLoading: true }}>
        {(state, setState) => {
          React.useEffect(() => {
            const timer = setTimeout(() => setState({ ...state, isLoading: false }), 3000);
            return () => clearTimeout(timer);
          }, []);

          return (
            <div style={{ maxWidth: "400px" }}>
              <SelectWithSummary
                options={state.isLoading ? [] : options}
                value={state.value}
                onChange={(val) => setState({ ...state, value: val })}
                loading={state.isLoading}
                placeholder="Choose options..."
              />
            </div>
          );
        }}
      </ValueProvider>
    );
  }}
</Cover>

## Error State

Displays error message with retry action.

<Cover kind={"card"}>
  {() => {
    const options = [
      { name: "JavaScript", value: "js" },
      { name: "TypeScript", value: "ts" },
      { name: "Python", value: "py" },
    ];

    return (
      <ValueProvider initialValue={{ value: undefined, hasError: true }}>
        {(state, setState) => {
          const handleRetry = () => {
            setState({ ...state, hasError: false });
          };

          return (
            <div style={{ maxWidth: "400px" }}>
              <SelectWithSummary
                options={state.hasError ? [] : options}
                value={state.value}
                onChange={(val) => setState({ ...state, value: val })}
                error={state.hasError}
                loadingError={state.hasError ? "Failed to load options" : undefined}
                retry={state.hasError ? { message: "Retry", action: handleRetry } : undefined}
                placeholder="Choose options..."
              />
            </div>
          );
        }}
      </ValueProvider>
    );
  }}
</Cover>

## Summary Error

      { name: "JavaScript", value: "js" },
      { name: "TypeScript", value: "ts" },

          };

          return (
            <div style={{ maxWidth: "400px" }}>
              <SelectWithSummary
                options={options}
                value={state.value}
                onChange={(val) => setState({ ...state, value: val })}
                hasInitialSummary={true}
                summaryErrorMessage={state.summaryError ? "Failed to load summary items" : undefined}
                retrySummary={state.summaryError ? { message: "Retry", action: handleRetrySummary } : undefined}
                summaryPreselectedValues={options.slice(0, 2)}
                placeholder="Choose options..."
              />
            </div>
          );
        }}
      </ValueProvider>
    );
  }}
</Cover>

## Uncontrolled

      { name: "JavaScript", value: "js" },
      { name: "TypeScript", value: "ts" },

## Accessibility

Properly labeled with ARIA attributes for screen readers.

<Cover kind={"card"}>
  {() => {
    const options = [
      { name: "JavaScript", value: "js" },
      { name: "TypeScript", value: "ts" },
      { name: "Python", value: "py" },
    ];

    return (
      <ValueProvider initialValue={undefined}>
        {(value, setValue) => (
          <div style={{ maxWidth: "400px" }}>
            <label htmlFor="lang-select" style={{ display: "block", marginBottom: "10px" }}>
              Select your preferred programming languages:
            </label>
            <SelectWithSummary
              id="lang-select"
              ariaLabel="Programming languages selector"
              options={options}
              value={value}
              onChange={setValue}
              placeholder="Choose languages..."
            />
            {value && (
              <div style={{ marginTop: "20px", padding: "10px", backgroundColor: "#f5f5f5" }}>
                <strong>You selected {value.length} language(s):</strong>
                <ul>
                  {value.map((v) => {
                    const opt = options.find((o) => o.value === v);
                    return <li key={v}>{opt?.name}</li>;
                  })}
                </ul>
              </div>
            )}
          </div>
        )}
      </ValueProvider>
    );
  }}
</Cover>
