## Overview
Basic Select component. Uses `latest/Button` for the trigger and options. The trigger `kind` and `em` props map directly to Button's API.

<Canvas of={SelectStories.Overview} />

The component can be imported from `@digital-science/figshare-fcl/Select`.

```jsx
import { Select, Option } from "@digital-science/figshare-fcl/Select";

<Select value={value} onChange={setValue}>
  <Option value="one">One</Option>
  <Option value="two">Two</Option>
</Select>
```
