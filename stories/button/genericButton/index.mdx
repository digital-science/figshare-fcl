## Overview

Similar to a Button component, but for contexts where we want to represent actions as links instead of boxed buttons.
Useful for when we want to display an action inline with text, 
or display a set of actions, close toghether or one after the other.


<Canvas of={GenericButtonStories.Overview} />



```jsx
import React from "react";
import Home from "@digital-science/figshare-fcl/icons/home";
import { GenericButton } from "@digital-science/figshare-fcl/button";

class MyButton extends React.Component {
  render() {
    return (
      <GenericButton tooltip="Tooltip text">
        Click me!
      </GenericButton>
    );
  }
}
```
